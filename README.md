## Reproducing everything

Every figure and result table in the report is generated by running, from
the project root:

```bash
python run_all.py
```

This runs, in order:

| Command | Produces |
|---|---|
| `python -m src.distances`   | `results/q1_timing.txt` (Problem 1) |
| `python -m src.poly_fitting`| `figures/q2b_*`, `figures/q2c_*`, `figures/q2d_*`, `results/q2_summary.txt` (Problem 2) |
| `python -m src.bias_variance`| `figures/q3b_*`, `figures/q3f_*`, `results/q3c_*`, `results/q3e_*`, `results/q3f_*` (Problem 3) |
| `python -m src.eda`         | `figures/q4b_*` … `q4e_*`, `results/q4a_*` … `q4f_*` (Problem 4) |
| `python -m src.ridge`       | `figures/q6a_*`, `figures/q6b_*`, `results/q6a_*`, `results/q6b_*` (Problem 6, optional) |

All random seeds are fixed (see `SEED = 42` in each module), so every
number and figure is exactly reproducible.

**Note on Problem 4 data loading:** `src/eda.py` first tries
`sklearn.datasets.fetch_california_housing`. If that download is blocked
(e.g. no internet access, or a firewalled machine), it falls back
automatically to the bundled `data_cal_housing.csv`, which contains the
identical 20,640-row dataset (same values, same column order) so results
are unaffected either way.
